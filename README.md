# **🖐️ Neon Aura AR**

Neon Aura AR is an immersive, high-performance browser experience that merges AI-driven hand tracking with generative art. Using MediaPipe for 21-point skeletal detection and the Web Audio API for real-time sound synthesis, the application transforms physical movements into a digital symphony of neon visuals and procedural audio.

# **✨ Key Features**

Gestural Interaction: Pinch to trigger shockwaves or use hand spreads to control visual intensity.

Reactive Visuals: High-speed particle physics, fingertip glow trails, and procedural lightning arcs.

Generative Sound: A synth-based hum that modulates pitch and volume based on the distance between your hands.

Thematic Environments: Real-time switching between Cyberpunk, Galaxy, Lava, and Ocean palettes.

Glassmorphism UI: A sleek, modern interface providing live FPS and gesture data.


# **🛠️ Tech Stack**

Vision: MediaPipe Hands

Graphics: HTML5 Canvas (Dual-layer system)

Audio: Web Audio API

Styling: Modern CSS (Glassmorphism & Neon UI)


# **🚀 Quick Start**
Clone the repository.

Open index.html in a modern browser (Chrome or Edge recommended).

Grant camera permissions and click "Enter Experience" to initialize the engine.
